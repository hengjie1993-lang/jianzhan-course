## 项目简介

这是一门把《阿无的建站教练课程》转化为**可交互、可训练、可落地**的网页课程。目标不是「读完」，而是把「找词 → 验证 → 设计 → 开发 → 上线 → 流量 → 变现 → 复利 → 退出」这套流程练成肌肉记忆。

2026-11-18 完成全面重构：原 21 课按主题合并去重为 **15 课（00–14）**，全部原文完整保留，并逐字融入 8 个全新模块（模块 A–H）。课程按「导论 + 第一篇到第五篇」分组。

课程面向想做英文利基站 / 微 SaaS 的独立开发者与中国自由职业者，覆盖 AI 时代的 SEO / GEO 新规则、AI 建站工程安全、收款合规、生命周期邮件与资产退出。

整个项目是**纯静态网页**，无后端、无数据库、无第三方运行时依赖。所有数据存在浏览器 `localStorage`，进度和笔记只属于你自己。

## 功能

| 模块 | 说明 |
| --- | --- |
| **课程** | 15 节课，按导论 + 五篇分组；含要点、案例、对比表、术语卡、一键跳转的工具链接 |
| **工具库** | 91 个实战工具，按「找词洞察 / 需求验证 / 建站开发 / 托管域名 / 收款变现 / 流量增长」等分类，支持搜索与筛选，点击直达官网 |
| **训练场** | 40 张术语闪卡（翻转 + 标记掌握）、24 道情境测验（含错因解析）、8 步流程排序、14 条新词研判清单 |
| **作战地图** | 六阶段流程主线（找词 → 验证 → 设计 → 开发 → 上线 → 增长），每阶段带工具与验收清单 |
| **实战工坊** | PRD 提示词生成器、4 条可直接复制的 AI 实战提示词（文案改写 / 上线审计 / GSC 诊断 / 竞品黑箱逆向）、本地笔记 |
| **进度与主题** | 学习完成度自动保存，明暗双主题切换，URL 始终同步当前视图与课号 |

所有学习内容集中在 [`data.js`](data.js)，渲染与交互在 [`app.js`](app.js)，视觉在 [`styles.css`](styles.css)。

## 课程结构

### 导论篇
- **00** 先跑通再完美：防过载执行路线图 —— 48 小时发射哲学（模块 A）+ 三阶段防超载清单

### 第一篇：需求发现与降维验证
- **01** 需求雷达：从「词句」到「美金」的流水线挖矿 —— 三种词根雷达 + 四副 X 光眼镜 + 机械化挖矿
- **02** 专业玩家的需求透视眼与 SERP 解剖学 —— 三板斧 + 意图四象限 + 五步解剖 + 真人访谈与竞品逆向（模块 B）
- **03** 黄金狩猎场与两条路线：游击套利 vs 品牌资产 —— 五大狩猎场 + 新词时间窗 + 终局路线抉择（模块 C）

### 第二篇：战前基建与产品打磨
- **04** 开局扫雷：域名选择、商标避坑与案底体检
- **05** 欧美原生感与信任工程（黄金 5 秒 + 15 秒 Aha!）
- **06** 零代码 AI 建站与生产级工程素养 —— 5 个零件 + 渲染 / 限流 / 安全 + 邮件送达基建

### 第三篇：流量矩阵与权威增长
- **07** 冷启动破冰：从 0 到 1 搞定全球免费流量 —— 四阶段作战 + 站外声量反哺排名（模块 D）
- **08** 抗算法惩罚的高级 pSEO 与多语言扩张时机
- **09** GEO 生成式引擎优化与数字 PR（外链公关）—— 可引用事实块 + 挣来的媒体曝光（模块 E）

### 第四篇：商业变现与资产退出
- **10** 变现引擎：定价防亏、付费墙 CRO 与 MoR / AdSense 通关
- **11** 留存印钞机：生命周期邮件营销与转化 A/B 实验（模块 F，全新独立一课）
- **12** 手术刀式运营循环与资产退出（Build to Sell）+ 模块 G

### 第五篇：垂直专题与实战附录
- **13** 垂直专题：游戏站 3 条路线的生死与上限
- **14** 实战附录：独立开发者 AI 提示词工具箱（4 条可复制提示词，含模块 H）

## 快速开始

### 在线使用

直接打开 https://hengjie1993-lang.github.io/jianzhan-course/

### 本地运行

```bash
git clone https://github.com/hengjie1993-lang/jianzhan-course.git
cd jianzhan-course
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

也可以直接双击 `index.html` 用浏览器打开，无需构建步骤。

### 深链参数

```
?view=course|tools|training|map|workshop   指定视图
?tab=flash|quiz|order|check                训练场标签
?mod=0-14                                  跳转指定课程（00–14，从 0 计数）
?theme=light|dark                          指定主题
```

翻页与视图切换会自动同步 URL，刷新后停留在同一位置。

## 技术栈

原生 HTML + CSS + JavaScript，零依赖、零构建、零框架。视觉采用 Cobalt 技术排版风格：Grotesk 标题、IBM Plex Sans 正文、JetBrains Mono 代码、单一钴蓝强调色、细线与切角面板。

通过 GitHub Pages 从 `main` 分支根目录自动部署，推送即上线。
